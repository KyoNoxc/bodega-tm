Bodega TM

Prototipo de inventario digital para Servicios Electromecánicos TM.

Permite ver de un vistazo qué herramienta, material y equipo tienen, en qué ubicación está (bodega, camionetas, en servicio) y su estado (disponible, en uso, dañado) — para no perder tiempo buscando cosas antes de salir a un servicio.

🔗 Demo: https://kyonoxc.github.io/bodega-tm/

Qué incluye


Búsqueda y filtro por categoría y ubicación
Tarjetas de cada ítem con código, estado y ubicación
Panel de detalle con historial de movimientos
Formulario para agregar ítems nuevos


Estado actual

⚠️ Esto es un prototipo visual. Los datos son de ejemplo y no se guardan — al recargar la página o abrirla en otro dispositivo, vuelve a mostrar la información por defecto.

Tecnología

HTML, CSS y JavaScript puro. Sin frameworks ni dependencias externas.
